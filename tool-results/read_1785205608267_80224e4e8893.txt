     3→/**
     4→ * Venom Arena — clean GameCanvas (BUILD-10 game-canvas fix).
     5→ *
     6→ * Every UI string and visual element in this file has been reconciled against
     7→ * AUDIT-A (the exhaustive audit of the original 4110-line GameCanvas.tsx).
     8→ * The HUD text, death screen, extraction screen, hold-to-extract popup, and
     9→ * quick-chat emotes bar all match the original strings character-for-character.
    10→ *
    11→ * Adapted to the BUILD-6a game-server changes:
    12→ *  - `GameSnapshot` no longer has `extractZoneRadius`. Extraction is button-
    13→ *    based (hold E or the bottom-right EXTRACT button anywhere in the arena).
    14→ *  - `SnakeSnapshot` now has `score` (body-length score). The HUD "Score:"
    15→ *    reads this directly (the snake length, not chips).
    16→ *  - Food: regular food = +1 score (grows body), NO chips. Star chips
    17→ *    (golden 5-point star) = +chips to carriedChips. The HUD "Carried Chips"
    18→ *    only goes up from star chips.
    19→ *  - Boost costs body length, not chips. Client sends `wantsBoost: true`
    20→ *    when SPACE is held OR the BOOST button is held OR the touch joystick
    21→ *    magnitude > 0.6. The server enforces the BOOST_MIN_LENGTH=8 gate and
    22→ *    drops 1 tail segment every 40 frames.
    23→ *  - Wall = death. The map has a breathing circular boundary
    24→ *    (radius 3800 ± 40, cycle 10 s). Rendered in render-helpers as a neon
    25→ *    rose circle. Hitting it kills you.
    26→ *  - World is 8000×8000, centered at (4000, 4000).
    27→ *
    28→ * High-level architecture:
    29→ *  - One socket effect (mount-once per arenaId) wires every server event with
    30→ *    a paired `.off(...)` cleanup. On `connect`/`reconnect` we re-emit
    31→ *    `join_arena` (the old canvas never did, leaving the player a ghost after
    32→ *    a blip). [FIXES C7, C8, S1, S2, S3]
    33→ *  - One canvas effect (mount-once) sets up the rAF loop, ResizeObserver, and
    34→ *    DPR-aware sizing. The loop reads purely from refs (no closures over
    35→ *    stale state). rAF is cancelled on unmount.
    36→ *  - One input effect (mount-once) wires mouse / keyboard / touch joystick
    37→ *    with `preventDefault` for arrows/space, blur-reset for stuck keys,
    38→ *    pointer-capture on the extract & boost buttons, and a virtual joystick
    39→ *    on the bottom-left quadrant of the canvas.
    40→ *  - Rendering math lives in `./render-helpers.ts` (pure functions, no React).
    41→ */
