### 3. Session Safety Scripts Built

#### `session-start.sh` (run at session start)
- Checks if `.git-credentials` exists and has a token
- Checks commit count (minimum expected: 50)
- Compares local HEAD hash with GitHub remote hash
- If mismatch → backs up DB and .env, fetches from GitHub, resets to origin/main, restores DB/.env
- Runs health checks (tier count, .env, database, node_modules, GitHub token)
- Auto-runs `bun install` if restore happened

#### `session-end-push.sh` (run at session end)
- Stages all changes (`git add -A`)
- Excludes `.git-credentials` from staging
- Auto-commits with timestamp
- Pushes to GitHub
- Reports success/failure
